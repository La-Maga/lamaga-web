Política de Privacidad

La privacidad de las personas que visitan este sitio web es importante para La Maga.

Datos personales

Este sitio web no recopila datos personales de manera automática.

Si una persona contacta voluntariamente a través del correo electrónico publicado en la web, los datos facilitados serán utilizados únicamente para responder a la consulta realizada.

Finalidad

Los datos que puedan recibirse mediante correo electrónico se utilizarán exclusivamente para gestionar la comunicación solicitada por el usuario.

Conservación de los datos

Los mensajes recibidos podrán conservarse durante el tiempo necesario para atender la consulta o mantener la comunicación iniciada por la persona interesada.

Cesión de datos

No se cederán datos personales a terceros salvo obligación legal.

Derechos

Cualquier persona podrá solicitar el acceso, rectificación o eliminación de los datos que haya facilitado mediante comunicación al correo electrónico de contacto publicado en este sitio web.

Enlaces a terceros

Este sitio web contiene enlaces a servicios externos y plataformas de terceros. La Maga no es responsable de las políticas de privacidad aplicadas por dichos servicios.
